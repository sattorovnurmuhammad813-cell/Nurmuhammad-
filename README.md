# Nurmuhammad-

Oddiy Telegram bot: `/start` bosilganda foydalanuvchiga salom beradi.

## Ishga tushirish

1. [@BotFather](https://t.me/BotFather) orqali bot yarating va tokenni oling.
2. Kerakli kutubxonalarni o'rnating:
   ```bash
   pip install -r requirements.txt
   ```
3. `BOT_TOKEN` muhit o'zgaruvchisini o'rnating (`.env.example` faylga qarang):
   ```bash
   export BOT_TOKEN=sizning_tokeningiz
   ```
4. Botni ishga tushiring:
   ```bash
   python bot.py
   ```
5. Telegram'da botga `/start` yuboring — u sizga salom beradi.
