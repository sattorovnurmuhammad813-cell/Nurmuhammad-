# Yunusobod tumani tibbiyot muassasalari

OpenStreetMap xaritasidan Yunusobod tumanidagi **barcha** shifoxona, tug'ruqxona,
poliklinika va klinikalarni joylashuvi (koordinata + Google/Yandex havola) bilan chiqaradi.

```bash
node tools/yunusobod-tibbiyot/fetch.mjs
```

Natija: `natija.csv` (Excel), `natija.geojson` (xarita), `natija.md` (havolali ro'yxat).
Kerak: Node 18+ va internet. Boshqa paket kerak emas.
